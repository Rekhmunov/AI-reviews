# Анализ: desktop-порт «Поставки — ВБ ФБС»

## Стек (зафиксирован)

| Компонент | Выбор | Причина |
|-----------|--------|---------|
| Python | **3.8.x** | Последняя ветка с поддержкой Windows 7 |
| UI | **PyQt5** | Qt5 работает на Win7; Qt6/PySide6 — только Win10+ |
| БД | **SQLite** | Полностью локально, без сервера |
| Сеть | только API WB | Marketplace + Content; веб FeedPilot не трогаем |

## Scope

**Включено:** источники, товары, категории, ручной sync, вкладки Новые/На сборке/В доставке, МГТ (create/add/choose), создание/добавление в поставку, карточка поставки, лист подбора (summary/extended), стикеры 58×40 с разделителями, QR, TRBX, маркировка (meta/sgtin), проверка ШК.

**Исключено:** ТСД, Вывод КИЗ / Честный знак / CryptoPro / Analytics, блок автоматики (шестерёнка / автосинк / автосбор МГТ).

## Зависимости настроек

- **Источники** — имя с «ФБС»/FBS + токен Marketplace (и Контент для названий).
- **Товары** — артикул/nmID, фото, `box_qty`, категория, `skip_kiz_gtin_check`.
- **Категории** — `boxes_per_pallet` для оценки палет и печати по категориям.

## Изоляция от веба

Каталог `desktop_wb_fbs/` — отдельное приложение. Файлы `review_processor/`, `web_*` в этой ветке не меняются.
